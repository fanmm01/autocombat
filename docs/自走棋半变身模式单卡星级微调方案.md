# 自走棋「半变身模式」单卡星级定向微调方案（Y17 / Y11 / Y6 / Y12）

> 适用范围：半变身模式（棋子 1/2 `.hs` + 召唤物 1/2 经典设定，基于已修复 `Y19` 与 `Y8` 后的 1830 场全池基准）。
> 约束条件：
> 1. **模式完全隔离（兼容非变身模式）**：本方案中的所有单卡星级覆写仅在 `ruleset == 'half_hs'`（半变身模式）下生效；**现有标准（非变身）模式（`ruleset == 'standard'`）完全不触发本方案任何改动**，确保非变身模式全池强度零滑动。
> 2. **严格隔离**：仅调整 `Y17`、`Y11`、`Y6`、`Y12` 四名棋子的指定星级，不改动其余 15 名棋子及这 4 名棋子未指定星级的任何数值。
> 3. **严格单调**：每名棋子的所有倍率、加成与技能数值必须满足 `1★ <= 2★ <= 3★`（核心成长项 `1★ < 2★ < 3★`），杜绝「2★ 新增或放大某能力、到 3★ 反而下降或消失」的情况。

## 2. 分棋子具体调整方案

### 2.1 `Y17 夜诏明`（目标：1★ 不变 ~26.3，2★ → ~35，3★ → ~63，均强 → ~41.4）

#### 问题诊断
- `Y17` 基础 `体格 = -2`（`db = -2`）、`HP = 9`（半 `.hs` 后 `49`，含 `hp_offset=3` 为 `52`）、`斗殴 = 28 / 弓术 = 61`，现行自走棋固定偏移（`hp_offset=3, dmg_pct_offset=15, flat_dmg_offset=1`）对三星一视同仁。
- 2★ 时仅吃全局 `+1 flat_dmg` 与 `1.65×` HP（`86 HP`），在半 `.hs` 2★ 动辄 100~170 HP 的环境里既站不住也打不动，导致 1★→2★ 仅涨 `+2.2`（`26.3 → 28.5`）；3★ 也仅 `51.0`。

#### 定向微调参数（1★ 保持原样，2★/3★ 严格递增）

| 生效属性（最终值） | 1★（不变） | 2★（原 → 新） | 3★（原 → 新） | 单调性 |
|---|---:|---:|---:|---|
| `hp_mult`（HP 星级倍率） | `1.00×` | `1.65×` → **`1.85×`**（约 86→96 HP） | `2.60×` → **`3.00×`**（约 135→156 HP） | `1.00 < 1.85 < 3.00` |
| `dmg_pct_offset`（总伤害%） | `+15%` | `+15%` → **`+30%`** | `+15%` → **`+42%`** | `15% < 30% < 42%` |
| `flat_dmg`（含全局+偏移） | `+1` | `+2` → **`+4`** | `+4` → **`+7`** | `1 < 4 < 7` |
| `flat_dr`（含全局） | `0` | `0` → **`1`** | `1` → **`2`** | `0 < 1 < 2` |
| `extra_bloodmoon_leech_pct`（额外吸血%） | `0%` | `0%` → **`+8%`** | `0%` → **`+15%`** | `0% < 8% < 15%` |
| `Y17-S003 凝血式-守` 减伤值 | `-1` | `-1` → **`-2`** | `-1` → **`-3`** | `1 < 2 < 3` |

- **预期效果**：
  - 1★ 完全不变（~`26.3`）；
  - 2★ 获得小幅坦度（`+12%` HP、`1` 减伤、`凝血式-守 -2`）与输出/续航（`+15%` 增伤、`+2` 固伤、`8%` 吸血），强度从 `28.5` 提升约 `+6.5` 至 **`~35`**；
  - 3★ 在完全承接 2★ 全部能力的基础上平滑递增，将 3★ 从 `51.0` 提升约 `+12` 至 **`~63`**，整体三星均强达到 **`~41.4`**（正好齐平 1G 档中位）。
- **校准旋钮**：实测时优先用 2★/3★ 的 `dmg_pct_offset`（±5%）与 `hp_mult`（±0.10）微调，保持 2★ 贴近 `35`、3★ 贴近 `63`。

### 2.2 `Y11 蓝`（目标：1★/2★ 不变，3★ 47.1 → ~55）

#### 问题诊断
- `Y11` 1★（`39.3`）与 2★（`45.9`）成长正常，但 2★→3★ 仅涨 `+1.2`（`47.1`）。
- 核心原因是 3★ 阶段全员血量翻倍以上，而 `Y11` 依赖近战镰刀直伤收割（`挥动镰刀 1d10+1d8+6`），缺乏百分比增伤与切入后排后的续航手段，3★ 经常差一刀斩杀被反杀。

#### 定向微调参数（1★/2★ 完全不变，仅增强 3★）

| 生效属性（最终值） | 1★（不变） | 2★（不变） | 3★（原 → 新） | 单调性 |
|---|---:|---:|---:|---|
| `dmg_pct_offset`（总伤害%） | `0%` | `0%` | `0%` → **`+20%`** | `0% = 0% < 20%` |
| `flat_dmg`（含全局+偏移） | `+1` | `+2` | `+4` → **`+6`** | `1 < 2 < 6` |
| `extra_bloodmoon_leech_pct`（额外吸血%） | `0%` | `0%` | `0%` → **`+12%`** | `0% = 0% < 12%` |

- **预期效果**：
  - 1★（`39.3`）与 2★（`45.9`）零改动；
  - 3★ 镰刀斩杀线提升约 `20% + 2` 固伤，并获得 `12%` 吸血续航，3★ 强度由 `47.1` 提升约 `+8` 分至 **`~55`**（均强 `44.1 → ~46.7`）。
- **校准旋钮**：若实测偏离 `55`，微调 3★ `dmg_pct_offset`（`15% ~ 25%`）即可。

### 2.3 `Y6 雪人`（目标：1★/2★ 不变，3★ 74.4 → ~68）

#### 问题诊断
- `Y6` 1★（`46.8`）与 2★（`51.0`）强度合理，但 3★ 飙升至 `74.4`（全池断档第一，比第二名高 `5.3` 分）。
- 原因是 3★ 吃满全局 `hp_mult=2.60×`、`summon_hp_mult=2.20×`、`skill_bonus=+20` 后，本体与 `小雪人` 生存与命中同时跨过阈值，极易在长回合里无限滚起跨循环冰冻（3 层 `2d10` 瞬回 + 持续回血回蓝 + 8 层控 `MOV=0` 与爆发 + `18%` 易伤）。

#### 定向微调参数（1★/2★ 完全不变，仅收敛 3★ 增幅且严格不低于 2★）

| 生效属性（最终值） | 1★（不变） | 2★（不变） | 3★（原 → 新） | 单调性 |
|---|---:|---:|---:|---|
| `hp_mult`（本体 HP 倍率） | `1.00×` | `1.65×` | `2.60×` → **`2.20×`** | `1.00 < 1.65 < 2.20` |
| `summon_hp_mult`（小雪人 HP 倍率） | `1.00×` | `1.50×` | `2.20×` → **`1.85×`**（小雪人 18→27→33 HP） | `1.00 < 1.50 < 1.85` |
| `skill_bonus`（技能命中加成） | `+0` | `+10` | `+20` → **`+14`** | `0 < 10 < 14` |
| `flat_dmg`（固定伤害加成） | `+0` | `+1` | `+3` → **`+2`** | `0 < 1 < 2` |
| `flat_dr`（固定减伤） | `0` | `0` | `1` → **`0`** | `0 = 0 = 0` |

- **单调性保证**：完全不削弱 `passive_rules.frost` 中的任何机制效果，不移除任何 2★ 已有能力；3★ 本体血量（`+33%` vs 2★）、小雪人血量（`+22%` vs 2★）、技能命中（`+4` vs 2★）、固伤（`+1` vs 2★）、MP（`1.55×` vs `1.25×`）依然 **全部严格高于 2★**，仅收敛了 3★ 过度膨胀的乘法增幅。
- **预期效果**：3★ 由 `74.4` 回调约 `-6.4` 至 **`~68`**（均强 `57.4 → ~55.3`），1★/2★ 完全不变。
- **校准旋钮**：微调 3★ `hp_mult`（`2.10 ~ 2.30`）与 `summon_hp_mult`（`1.75 ~ 1.95`）。

### 2.4 `Y12 斯瑞提卡`（目标：1★/2★ 不变，3★ 66.6 → ~70）

#### 问题诊断
- 半变身模式下召唤物统一为 1/2 经典设定后，`Y12` 的 1★（`42.5`）与 2★（`57.5`）表现均衡，3★（`66.6`）略低于一线 3★ 大核的 `68~70` 区间。

#### 定向微调参数（1★/2★ 完全不变，仅增强 3★）

| 生效属性（最终值） | 1★（不变） | 2★（不变） | 3★（原 → 新） | 单调性 |
|---|---:|---:|---:|---|
| `summon_hp_mult`（召唤物 HP 与护盾格挡倍率） | `1.00×` | `1.50×` | `2.20×` → **`2.50×`** | `1.00 < 1.50 < 2.50` |
| `summon_skill_bonus`（召唤物攻击技能加成） | `+0` | `+8` | `+16` → **`+22`** | `0 < 8 < 22` |
| `flat_dr`（本体固定减伤） | `0` | `0` | `1` → **`2`** | `0 = 0 < 2` |

- **3★ 召唤物数值变化参考**：
  - `玄武`：`110 HP / 132 盾格挡` → **`125 HP / 150 盾格挡`**
  - `朱雀`：`84 HP` → **`95 HP`**
  - `龙虎`：`136 HP` → **`155 HP`**
  - `三合一`：`220 HP / 55 盾格挡` → **`250 HP / 63 盾格挡`**
- **预期效果**：1★（`42.5`）与 2★（`57.5`）零改动；3★ 强度由 `66.6` 温和提升约 `+3.4` 至 **`~70`**（均强 `55.5 → ~56.7`）。
- **校准旋钮**：微调 3★ `summon_hp_mult`（`2.40 ~ 2.65`）。

## 3. 代码落地方式与单调性防回退保障（设计参考）

为避免在代码里散落 `if serial == ... and star == ...` 硬编码导致维护困难或误伤其他棋子，建议后续实施时在 `backend/autochess_catalog.py` 中新增集中式配置表 `HALF_HS_STAR_OVERRIDES`：

```python
HALF_HS_STAR_OVERRIDES = {
    'Y17': {
        2: {'hp_mult': 1.85, 'extra_dmg_pct': 15, 'extra_flat_dmg': 2, 'extra_flat_dr': 1,
            'extra_bloodmoon_leech_pct': 8, 'guard_dr': -2},
        3: {'hp_mult': 3.00, 'extra_dmg_pct': 27, 'extra_flat_dmg': 3, 'extra_flat_dr': 1,
            'extra_bloodmoon_leech_pct': 15, 'guard_dr': -3},
    },
    'Y11': {
        3: {'extra_dmg_pct': 20, 'extra_flat_dmg': 2, 'extra_bloodmoon_leech_pct': 12},
    },
    'Y6': {
        3: {'hp_mult': 2.20, 'summon_hp_mult': 1.85, 'skill_bonus': 14, 'flat_dmg': 2, 'flat_dr': 0},
    },
    'Y12': {
        3: {'summon_hp_mult': 2.50, 'summon_skill_bonus': 22, 'flat_dr': 2},
    },
}
```

### 配套保障措施
1. **非变身模式零侵入隔离**：
   - `apply_autochess_modifiers(..., ruleset='standard')` 仅在 `ruleset == 'half_hs'` 时读取 `HALF_HS_STAR_OVERRIDES`；`ruleset == 'standard'` 直接走现行 `STAR_SCALING` 与 `UNIT_CATALOG`，绝不修改全局 `UNIT_CATALOG`、`STAR_SCALING`、`ALL_CHARACTERS` 或 `SUMMON_TEMPLATES`。
   - `Y17` 的 `凝血式-守`（`Y17-S003`）星级减伤改写仅作用于 `apply_autochess_modifiers` 内部的 `cdata = copy.deepcopy(raw)` 副本，且严格受 `ruleset == 'half_hs'` 门控，不触碰原角色模板与非变身模式。
   - **默认参数向后兼容**：所有既有调用方（`pve12`、`lobby4`、`pvp_room`、`ranked` 及现有单测）不传 `ruleset` 时一律默认 `'standard'`，历史存档反序列化缺省 `ruleset` 时同样回落 `'standard'`。
   - **共享改动联动复核**：由于此前 `Y19`（`ai_tactics.py`）与 `Y8`（`BIHAMI_CAKE_SCALING`）改动位于两模式共享路径，落地验收时同步对 `ruleset == 'standard'` 跑一轮 `autochess_power_rating.py` 基线回归，确认非变身模式整体强度与费用梯度未发生非预期大滑动。
2. **单调性与隔离单元测试**：
   - 遍历 `HALF_HS_STAR_OVERRIDES` 中每名棋子，计算 `half_hs` 下 1★/2★/3★ 实际生效的 `hp_mult`、`mp_mult`、`skill_bonus`、`flat_dmg`、`flat_dr`、`dmg_pct`、`summon_hp_mult`、`summon_skill_bonus`、`bloodmoon_leech_pct` 及技能特殊参数，强制断言 `val(1★) <= val(2★) <= val(3★)`，从机制上杜绝星级倒挂；
   - 新增隔离断言：验证 `ruleset == 'standard'` 下 `Y17`/`Y11`/`Y6`/`Y12` 的 1★/2★/3★ 生效属性与 `HALF_HS_STAR_OVERRIDES` 上线前完全一致（零差异）。
3. **图鉴按模式分流展示**：在 `build_unit_wiki(serial, ruleset='standard')` 中仅当 `ruleset == 'half_hs'` 时追加展示本方案的星级强化说明，非变身模式图鉴保持原样不产生误导。
4. **聚焦回归验证**：落地后使用 `scripts/analysis/autochess_power_rating.py --ruleset half_hs --focus Y17/Y11/Y6/Y12` 做大样本聚焦验证，再分别跑 `half_hs` 与 `standard` 全池回归，双向确认目标达标且非变身模式无强度滑动。
