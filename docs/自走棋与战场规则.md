# 星序自走棋与空间战场规则

> 本文档说明演进后的**自走棋模式（`autochess_mode=True`）**及其对应的坐标寻路、地形、经济、升星与双轴羁绊规则。**经典模式（自由对战、锦标赛、剧情战斗及所有既有回归赛制）保持 `autochess_mode=False` 原状，不受任何改动。**

---

## 1. 双模式并行原则

| 维度 | 经典模式 (`autochess_mode=False`) | 自走棋模式 (`autochess_mode=True`) |
|---|---|---|
| 启用方式 | 全部默认入口、`/api/pvp/*`、`sim.py` 默认 | 前端 `/ui/autochess`、`/api/ui/autochess/*`、`sim.py --autochess` |
| 射程判定 | 保持 `GLOBAL_RANGE_OVERRIDE = 1` 原规则 | 忽略全局覆盖，使用 `AUTOCHESS_RANGE_OVERRIDES` 与真实切比雪夫射程 |
| 回合末站位 | 消耗剩余移动力弹回初始锚点 | **保留场上站位**（不再弹回锚点），战前排阵与走位具备持续价值 |
| MOV 与动作池 | 主动作数 = `max(1, (有效MOV+1)//5 + 额外)` | **主动作公式严格保持不变**；仅缩放移动格数预算 `min(8, max(2, ceil(eff_mov/2)))`（0速为0） |
| 卡牌范围 | 含 `Y1–Y17` 与 `Y60`（18 角色） | 默认共享牌库仅收录 17 位独立魔法少女（`Y1–Y17`，不含 `Y60`） |

## 2. 坐标、寻路与地形系统（`backend/grid_nav.py` / `backend/arena_presets.py`）

- **8 向切比雪夫距离**：`grid_dist(a, b) = max(|col_a - col_b|, |row_a - row_b|)`，兼容 `A1–P16`（可扩展至 `Z26`）。
- **Dijkstra 有界寻路与卡位**：
  - 地面单位不可进入墙体与敌方占位格，可穿过友军但不可停留重叠，并禁止从两堵斜邻墙角夹缝穿行。
  - 飞行单位可越过墙体与战场单位但不可重叠停留；自走棋模式下，飞行单位发动距离 `<= 2` 的近战俯冲后至回合结束前可被地面单位反击近战。
  - 支持 `2×2` 大体型召唤物占地与推拉位移判定。
- **4 张严格镜像对称战场预设**：
  1. `autochess_standard`（星序标准盘 `10×7`）：Y 部署列 `A-C`，X 部署列 `H-J`，中场 4 处对称掩体 `D3, D5, G3, G5`。
  2. `autochess_compact`（近战演武盘 `8×6`）：快节奏近身交战，`D2, D5, E2, E5` 掩体。
  3. `autochess_citadel`（双柱要塞盘 `12×8`）：墙柱 `E3, E6, H3, H6` 形成双路侧翼，外侧掩体与中央 4 格灵脉 `F4, G4, F5, G5` 并存。
  4. `classic_open`（开阔演武盘 `10×10`）：无障碍经典对称方盘。
- **三大地形效果**：
  - **墙体 (`wall`)**：阻挡地面移动与布阵（飞行单位可越过）。
  - **掩体 (`cover`)**：地面进入消耗 `2` 点移动力（飞行无视消耗）；站在掩体中受到距离 `>= 3` 的远程伤害降低 `15%`。
  - **灵脉 (`leyline`)**：每轮开局位于灵脉格上的存活单位恢复 `+1 MP`。
- **加时决战压迫**：1v1 从第 `12` 轮、多人从第 `15` 轮起进入加时，每轮全伤害递增 `+15%`、治疗逐步衰减（最低降至 `25%`），防止无限拖平。

## 3. 自走棋核心玩法（`Y1–Y17`）

### 3.1 有限公共牌库与星级合成
- **费用阶梯与共享总张数**：
  - **1 费**（每卡 `18` 张）：`Y1 炎焱`、`Y3 灵牛`、`Y8 比哈米`、`Y10 春晌`、`Y11 蓝`
  - **2 费**（每卡 `15` 张）：`Y4 星闪`、`Y6 雪人v2`、`Y7 环花暖`、`Y14 余烬`
  - **3 费**（每卡 `12` 张）：`Y2 达尼厄斯`、`Y5 血天使`、`Y9 木落`、`Y13 “巨人”`、`Y15 葬火`
  - **4 费**（每卡 `9` 张）：`Y12 斯瑞提卡`、`Y16 罗杰`、`Y17 夜诏明`
- **牌库守恒**：场上 + 备战席购入即从公共牌库扣除；出售或指挥官淘汰时按 `3^(star-1)` 原数退回公共牌库。
- **三合一升星**（适配 CoC D100 检定曲线）：
  - `1★ → 2★`：HP ×`1.65`、MP ×`1.25`、技能检定 `+10`（上限夹紧 `92`）、基础增伤 `+1`、召唤物 HP ×`1.5` / 技能 `+8`
  - `2★ → 3★`：HP ×`2.60`、MP ×`1.55`、技能检定 `+20`（上限夹紧 `92`）、基础增伤 `+3`、固定减伤 `+1`、召唤物 HP ×`2.2` / 技能 `+16`

### 3.2 经济、等级、8 羁绊与星序祝福
- **经济公式**：每轮结算获得基础金币 + 利息（每存 `10G` 获 `+1G`，基础上限 `+5G`）+ 连胜/连败奖金（2/3/5+ 分别 `+1/+2/+3`），同时自动获得 `+2 XP`。
- **等级与人口**：`Lv.1 → Lv.5` 对应基础人口 `2 → 6`（购买 `+4 XP` 需 `4G`，刷新商店需 `2G`）。
- **8 个双轴羁绊**（每角色拥有 2 个特质标签）：`炎域`、`星祈`、`重盾`、`血月`、`武斗`、`灵召`、`破空`、`秘愈`（涵盖百分比/斩杀增伤、轮首回蓝与冷却缩减、前排掩体减伤、全能汲取溢盾、技能穿伤、召唤物倍增、移速射程扩展与全队开局护盾）。
- **星序祝福**：第 `4` 与第 `8` 回合触发 3 选 1 永久局内强化（涵盖利息上限、免费刷新、人口突破、吸血、阵域扩展、召唤统御等 14 项祝福）。

## 4. 空间战术 AI 与命令行模拟

- **战术 AI（`backend/ai_tactics.py`）**：
  - 战前按角色定位（`tank` / `bruiser` / `assassin` / `ranged` / `support` / `summoner`）与指挥官设定的**战术姿态**（激进 / 均衡 / 稳健）排定前中后排；
  - 战中综合击杀收益、残血集火、AOE/控场、危险领域规避、掩体/灵脉占点与治疗/复活救援进行决策，并在战报栏显示人类可读战术意图。
- **命令行体验自走棋单场/批量对战**（默认不变，显式加 `--autochess` 启用）：
  ```bash
  python backend/sim.py Y1+Y7 vs Y2+Y4 -n 20 --autochess --arena autochess_standard
  python backend/sim.py Y12+Y9+Y10 vs Y16+Y4+Y8 -n 10 --autochess --arena autochess_citadel -v
  ```
- **平衡验证与 AI 权重训练**：
  ```bash
  python scripts/analysis/autochess_balance.py
  python backend/autochess_trainer.py --generations 4 --pop 8 --matches 6 --workers 4
  ```
