# 历史归档

- `reference/`：旧实现、规则参考、卡片及原始资料。
- `artifacts/`：以往验证记录、截图、平衡性评估及性能报告。
- `backups/`：项目原有的角色数据备份。
- `outputs/`：整理前位于根目录的日志副本、矩阵和赛事输出。
- `tools/`：临时实验、进程管理和未命名脚本，保留内容供追溯。

这些资料不进入发布包。历史脚本保留原有路径和行为，查阅后再决定是否迁回正式工具。
活动测试位于 `../dev/`，继续由 Git 管理。部分 Python 回归仍引用这里的历史基线。
整理迁移记录位于 `reorganization-20261116.json`；完整工作区备份存放在项目外。
