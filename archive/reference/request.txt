甲.战斗规则
一、总流程
a)先攻与位置初始化：
.bta new/import 主持人将提前准备好的npc及其技能、阵营、初始位置表导入至地图中。场景已经预制好，将给出包含入口与障碍物表在内的空地图。

.hs 单个魔法少女变身。

.bta int （team=Y，X与Z一般分配给非主角团方） pos=[F/M/B/格序号]   (card=本群卡)
通过此指令，全自动加入战局之中，并确定站位为前/中/后部，或自定义的、位置距离入口不超过一行动力距离的地方，并自动投掷敏捷确定回合顺序。

.bta start
在全部玩家初始化后，开始战斗。
开始战斗使得尚未完成变身的全体pc和npc立刻完成魔法少女变身，此后生命值变为原先的（5+level）倍，魔力值变为原先的（2+0.5*level）倍，可以施用一切法术。详见乙部。
将列举出全部参加战斗的人物-编号键值对。
战斗中所使用的编号，对于魔法少女们是：
阵营名加上魔法少女编号，一个固定值。
对于敌人，则书“X0”“Z0”等，编号从0开始依次排列，前缀有所不同但一般地为X。编号可以用“Ys”“Zs”“Xs”代指同阵营全部人，“Yr”指代同阵营随机人，大写S指代自身。

随后，正式进入战斗。

二、战斗流程

战斗过程中，每一回合由如下几个部分组成。
① 回合前准备阶段。在战斗开始，或一个回合结束下一个回合开始前，将会给出此时的地图。
② 回合中阶段。其中，除非被禁止行动，那么每名参与战斗的角色都拥有一个回合，每个回合含有三次附加动作机会与两次主动作机会。
③ 回合后结算阶段。结算伤害，所有成回合消耗，所有回复。每经历一次这个阶段，持续时长大于1回合的技能效果被执行一次，剩余回合数减少一个；吟唱回合数大于1回合的技能剩余回合数减少一个。
其中，回合中阶段中每个个体：
1.回合开始
2a.附加动作1
3a.第一次行动
2b.附加动作2
3b.第二次行动
2c.附加行动3
4.结束回合

一次行动指：一次角色卡中说明为「回合内」的技能、一次攻击。
一次附加动作指：角色卡内说明不占用回合数的技能、一次移动，或/和一次非战斗骰点（如侦查）。

三、回合流程
一次一人回合的标准流程如下：

0.开始回合。声明第一次附加动作，如果有的话。
1.进行主动作。声明其针对对象。以主动作为伤害技能为例：
a.如果主动作使用技能不是必定成功，那么投掷主动作的进攻骰，判断其是否成功。
b.（如果这是可能的），那么对手选择反应动作，并投掷反应骰。
反应动作包括闪避、反击、以及设定为“反应动作”的其他技能。
闪避每在成功以上一个等级，则成功等级-1；闪避为大失败时，成功等级+1。反击采用原版规则，但是仅限于使用近战技能（技能栏旁边追加「可反击」tag的那些）。
c.如果攻击奏效且伤害期望大于6，且受攻击的并非pc，那么投掷致死骰。致死骰的面数为敌方最大生命值的二倍，成功阈值为伤害期望，或者对技能来讲自己设定的数值。当出目小于成功阈值时，则敌方将立即死亡或丧失战斗能力，立即退出战斗。
d.如果命中且不触发致死，那么，投掷伤害；若未命中，跳过该步骤。
e.重复0-4步骤一次。

3.由主持人与此回合的玩家分别对此回合的动作、反应以及结果进行描述。
玩家可以选择将动作/反应的文字描写置于相应行动之前，或把自身行动的描写整个置于第一个附加动作之前。这在一场战斗中至kp进行重置次数前最多发生三次。如果该描绘是精彩的，则这一行动可以被赋予一个奖励骰。

.a 附加动作
.c/不写 主动作

如果有近战攻击，那么自动移动。
如果为远程技能，那么默认不移动。但是，如果这个人在攻击范围之外，那么移动。
——主动的

五、战斗结束与魔法升级
战斗结束后，通过.bta end 来完成战斗轮。

乙）变身与魔法规则
一、变身效果（.hs）：
生命值变为原先的（5+level）倍；
魔力值变为原先的（2+0.5*level）倍；
app+=60，但不超过80；
格斗、闪避、枪械等战斗技能+=20，但不超过80；
体格+1，db变为其上一个等级；
行动力+2。
```
HP   = HP_original  × (5 + level)
MP   = MP_original  × (2 + 0.5×level)
APP  = min(APP_original + 60, 80)
Brawl/Dodge/Firearms += 20 (上限 80)
Build += 1 → DB 上升一级
MOV  += 2
```

二、解除变身效果（.unh）：
 1.生命值变为（上取整(hp/(等级+5))+2）； 
2.mp变为：若大于变身前最大mp则舍去多余值，否则不变。 
3.若此次变身中使用了超过两次法术或进行了战斗，则sc0/1d5，并进行体质检定，若失败则永久减少1d3的体质值。随着数值变化的进展，以上数值的改变会逐渐增大，具体地：SAN≥30: 0/1d5, CON 1d3/0; SAN<30: 1/1d6, CON 1d3+1/0; SAN<20: 1d3/1d8, CON 1d6/1d3; SAN<CM 损失减半。若该减少引起最大生命值变化则依照此变化最大生命值。
4.回复初始属性技能。
 5.在第（1，3，6，10，15，……）次有效变身后等级加一。详见“升级规则”栏目。

三、升级规则与魔能进阶
1.等级达到（4，8，……）将使你有机会习得一【深层魔法】；
2.等级达到（2，6，10，……）则可以使你有机会获得一个新的浅层魔法。请在初始时确定等级2对应的浅层魔法。
3.任意一次升级，可以选择一个已经掌握的魔法，使之获得熟练度*30。此外，如果某一个魔法在释放时达到大成功或成功终结，那么熟练度也会获得30，任意一次使用了该技能的战斗会结算中将熟练度+1d20。
熟练度达到30，60，90将使其分别获得一个升级。这一升级应当与kp商议，效果应是较小的，如伤害骰/护盾骰从d4-d6-d8-d10-d12，或吟唱时间减1/4以内，持续时间+1/3以内，致死骰+2，领域半径+1格等。这个升级只能是单一过程。熟练度达到100，则可以对魔法进行一次深化，将其升级为一个更为深层的模式。
第一个深层魔法应由kp在pl车卡时拟定者的基础上做出符合剧情的加工。
一个与时间相关的魔法必然是深层魔法。
部分内容可以增长cm值。代替原版克苏鲁神话技能，此处的cm意味变为对魔法知识与世界的本源的了解程度。对需要用到该技能的位置，掷骰为一次灵感与.rd+cm的组合，kp给出一个成功值，出目越大越好。可以使用如下指令快捷掷骰：.cm。另外地，驾驶与信用也用.rd+信用/驾驶代替.ra信用+驾驶。
