## Y14 麦知夏 — 卡带系统（4 阶段）

**属性**：HP 14 / MP 10 / MOV 7 / 斗殴 70 / 闪避 60 / db 1d4 / 伤害骰 1d4+db  
**特色**：4 阶段卡带切换 + 模式切换 + 极限槽 + 金环 + 残机替身

### 核心机制：阶段 = 卡带

- 初始阶段 2（最终幻想）。`phase: 0` 的法术全阶段通用。
- 通过附加动作（timing='3'）切换卡带，消耗 2 MP，引擎 `_transition_phase()` 处理。
- `load_spells()` 按阶段过滤法术，仅加载当前阶段 + phase=0 的法术。
- 切换时旧阶段效果（buff/zone 等）正常持续。

### 爆破圈触发逻辑
- timing='4'：被动反应法术。角色首次受到攻击时自动触发火焰爆破，对攻击者造成伤害 + DOT。
- `_once_per_battle=True`：整场仅触发一次。
- 在 `_coc7_attack` 受击路径中 hook。

### 火鼠裘分段减伤逻辑
- damageModifier (type=12) 在护盾吸收**前**应用：
  - 伤害 ≤ 3 → 免疫（0 伤害）
  - 3 < 伤害 < 7 → 伤害上限为 3
  - 伤害 ≥ 7 → 伤害 ×0.6
- 每次触发消耗 1 MP。MP 不足则不减伤。
- 在 `_apply_spell_damage` 的护盾之前 hook。

### 飞行近战限制
- 引擎配置 `FLYING_MELEE_RULE`（默认 2）：
  - 2 = 完全阻止近战命中飞行单位
  - 1 = 惩罚骰
  - 0 = 无影响

### 月能系统（引擎数据驱动实现）

#### 充能来源
| 来源 | 比例/值 | 引擎 Hook |
|------|---------|-----------|
| HP 溢出 | 1:1 | `_execute_spell` type=3 治疗→HP 超过上限部分 |
| MP 溢出 | 1:1 | `_execute_spell` type=3 治疗→MP 超过上限部分 |
| s1 灵感大爆发 | 2d3 | `charge_moon` 字段（法术级）→ type=4 施放后 |
| s6 即兴短句 | 2 + 写作加值 | `charge_moon` 字段（效果级）→ `_handle_spell_damage_effect` 幻造分支 |
| 然遥远的理想城·护盾破碎 | 破碎值 | （待实现） |

#### 消耗路径
| 路径 | 消耗 | 引擎 Hook |
|------|------|-----------|
| 每回合补满友方 HP/MP | 按需 1:1 | `_tick_down`: `replenish_allies` summon → 补满 linked buff 持有者 |
| 重伤时授予月相庇佑 | 5 | `_tick_down`: `hp_threshold_grant` → HP < 50% 时扣 5 月能授予 AUX 30 |

#### 其他月能机制
- **MP 无上限**：`unlimited_mp` 模板字段 → `_create_summon` 设魔力上限=99999
- **变身 MP 减免**：`_mp_formula_transformed='2d3'` → 变身时 s2 消耗 2d3 而非 3d4
- **linked_summon**：buff 有效期 = 召唤物存续时间；召唤物死亡下一 tick 自动过期

### 月相的庇佑（AUX 30 免疫一次伤害）

- **消费**：`_consume_immunity(uid)` → 检查 auxCode=30 → 设 remainingRounds=0，本次伤害归零
- **Hook 点**：
  - `_apply_spell_damage`（法术伤害前）
  - `_coc7_attack`（基本攻击伤害前）
  - `_absorb_damage_with_shield`（所有伤害吸收前）
- **授予**：`_apply_immunity_buff(uid)` → 创建 stackable AUX 30 buff（月相的庇佑）
- **克隆保护**：影之克隆被攻击时 → 同 owner 的其他克隆 + 主人自动获得月相庇佑（`protect_allies_on_hit` 模板字段）

### 幻造兵武系统

- **s5 幻造兵武**（被动）：施加 type=4 buff → auxVal=1d6 伤害加值
- **幻造前缀法术**（如 s6）：effect 标记 `幻造=True` → 伤害前掷 写作(70) 检定：
  - 大成功(≤5): +2d6
  - 极难(≤14): +6+1d6
  - 困难(≤35): +1d6
  - 成功(≤70): +1d3
  - 失败: 无加值
  - 大失败(96-100): -1d2
- **普攻也适用**：`_coc7_attack` 在飞行检查后、反应 hook 前，检测攻击者是否有幻造兵武 buff → 掷写作检定 → 追加 dmg_dice

### 武器系统

- 默认武器：`staff`（法杖）
- 武器切换法术（s7-s9）：timing='123'（自由动作，不占主动/附加），type=17 stateToggle
- `weapon_required` 过滤：`load_spells()` 根据当前 `_weapon_name` 过滤法术
- 武器锁定终极技：
  - **弓** → s10 万众瞩目的乌托邦（吟唱 3 回合）
  - **法杖** → s11 已然遥远的理想城（全体 2d4 护盾）
  - **剑** → s12 月光王座全额率输出（消耗全部月能）

## 引擎层面通用机制（数据驱动）

以下机制通过 chData 字段驱动，不由引擎硬编码法术名：

| 字段 | 级别 | 效果 |
|------|------|------|
| `linked_summon` | 效果 | buff 链接到召唤物存活，召唤物死亡后下一 tick 过期 |
| `unlimited_mp` | 模板 | 召唤物 MP 无上限 |
| `replenish_allies` | 模板 | 召唤物每回合消耗 MP 补满 linked buff 友方 |
| `protect_allies_on_hit` | 模板 | 召唤物被攻击时同组其他成员+主人获得 AUX 30 |
| `charge_moon` | 法术/效果 | 施放时充能 replenish_allies 召唤物 |
| `hp_threshold_grant` | 效果 | HP 低于比例时消费召唤物 MP 授予指定 AUX |
| `_mp_formula_transformed` | 法术 | 变身时 MP 消耗替换公式 |
| `clone_of_owner` | 模板 | 召唤物继承主人法术和属性 |
| `幻造` | 效果 | 触发幻造兵武写作检定追加伤害 |
| `weapon_required` | 法术 | 武器状态过滤 |
