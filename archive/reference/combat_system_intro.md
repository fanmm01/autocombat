# autocombat 战斗系统简介

> v1.4.0 — COC7 扩展魔法少女半自动战斗系统
>
> 前置依赖：loganalyser / logutil v5.0+

---

## 甲、战斗规则

### 一、总流程

#### 1. 初始化

战斗开始前，主持人（KP）需预先准备好场景地图、NPC 数据及其阵营、初始位置。

```
.bta new <名称>    新建战斗模板
.bta map [W*H]    查看/设定地图（默认 10×10，入口位于 A 列总行数二分之一处，上取整）
.bta add Y12 A1   将 Y12 导入地图 A1 格
.bta map add X*Y A11 blank  扩展地图（左上角 A11）
.bta map add X*Y F5 none    设置障碍物
.bta save          保存预设
```

#### 2. 玩家入场与变身

```
.hs               单个魔法少女变身（详见乙部）
.bta int [team=Y/X/Z] [pos=F/M/B/格序号] [card=本群卡]
                  全自动加入战局，站位为前/中/后部或自定义格（距入口 ≤ 一行动力）
.bta start        全体未变身 PC/NPC 立刻完成变身，战斗开始
```

> **变身效果（.hs）**：HP → HP×(5+level)；MP → MP×(2+0.5×level)；APP+60（≤80）；斗殴/闪避/枪械+20（≤80）；体格+1，DB 上升一级；MOV+2。

#### 3. 先攻

战斗开始时，每名角色掷 D100 对抗「敏捷」确定先攻顺序。高成功等级者优先行动；同等级者按敏捷高低、投掷出目排序。

每名角色在先攻表中仅占**一个条目**。当前场上角色的标识格式：
- 魔法少女：`阵营名 + 魔法少女序号`（如 Y1, Y12）
- 敌方/NPC：`X0`, `Z1` 等（前缀为阵营名，编号从 0 起）

快捷指代：`Ys`/`Xs`/`Zs` = 同阵营全体；`Yr`/`Xr` = 同阵营随机一人；大写 `S` = 自身。

### 二、战斗流程

每回合由三个阶段组成：

| 阶段 | 内容 |
|------|------|
| **① 回合前准备** | 展示当前地图。首回合或新回合开始时触发 |
| **② 回合中** | 每名角色依次行动。每回合拥有 **N 次主动作** + **3 次附加动作** |
| **③ 回合后结算** | 结算所有持续效果（tick down），回合数递减；领域效果结算；MP 自然回复 2d6 |

> **主动作次数 N** = `max(1, 有效MOV // 5 + 额外行动数)`（无上限）
>
> 默认情况下（MOV=8, 额外行动数=0），每回合 **1 次**主动作。飞行角色 MOV+8，可获得更多。额外行动数可由角色/召唤物模板显式设置。

**单个角色的行动结构**：
```
┌─　　回合开始　　　　　　　　　　　　　　　　　　　　　　　　　　┐
│  1a. 第一次主动作（.s0 或 .sN）　　　　　　　　　　　　　　　　│
│  2a. 附加动作（.a m / .a sN / .a eat / .a give — 任一）      │
│  1b. 第二次主动作                                              │
│  2b. 附加动作                                                  │
│  1c. 第三次主动作                                              │
│  2c. 附加动作                                                  │
│  ……（继续执行全部主动作，主动作耗尽或 .i end 后轮到下一角色）   │
└─　　回合结束 → .i end 或主动作用尽　　　　　　　　　　　　　　　┘
```

### 三、回合流程（一次主动作的标准流程）

以攻击技能为例：

1. **声明目标**：指定技能与目标对象（支持单体/群体/领域中心点等）。
2. **进攻检定**（若非法术必中）：投 D100 对抗技能值，计算成功等级（大失败=-2 / 失败=0 / 成功=1 / 困难=2 / 极难=3 / 大成功=4）。
3. **反应阶段**（若目标可反应）：防御方选择反应动作：
   - `.e d` / `.e 闪避` — 闪避
   - `.e c` / `.e 反击` — 反击（仅限有「可反击」tag 的近战技能）
   - `.e b` / `.e 格挡` — 格挡（需有盾牌/格挡技能）
   - **击晕状态禁止所有反应**，攻击直接命中。
4. **对抗结算**：
   - 闪避每成功一级，攻击方成功等级 -1；闪避大失败则 +1。
   - 反击胜出（等级高于攻击方且 >0）→ 防御方反造成伤害，原攻击化解。
   - 等级相等且均 >0 → 双方互中。
5. **伤害投掷**（命中时）：

   | 最终成功等级 | 伤害结算 |
   |-------------|---------|
   | 困难成功(2) | 伤害骰优势（两次取大） |
   | 极难成功(3) | 不贯穿→满值；贯穿→满值+伤害骰 |
   | 大成功 2-5(4) | 不贯穿→满值+伤害骰；贯穿→满值×2 |
   | 大成功 1(4) | 满值×2 |

6. **致死判定**：若伤害期望 > 6 且目标非 PC，投掷致死骰。骰面 = 目标当前生命值×2，阈值 = 伤害期望。出目 ≤ 阈值 → 立即死亡/退出战斗。
7. **护盾吸收**：若目标有护盾，伤害先扣护盾再扣 HP。
8. **描述**：玩家可在行动前附加文字描写。精彩的描述可由 KP 赋予一次奖励骰（每场战斗限 3 次，至 KP 重置）。

### 四、战斗掷骰命令速查

#### 主动作

| 命令 | 说明 |
|------|------|
| `.s0` | 基本攻击（使用最高近战技能，自动移动至射程内） |
| `.sN [目标]` | 释放第 N 号技能（N 从 1 开始）。目标可写序号/坐标/`Ys`等指代 |
| `.bta s1 s2 X0` | 一键完成主动作（含预设防御方反应） |
| `.bta s1Y1 s2X2` | 逐行动指定目标 |
| `.bta a1s4 a3D6 s2 s3 Xr` | 附加动作 + 主动作复合 |

#### 附加动作

| 命令 | 说明 |
|------|------|
| `.a m <坐标>` | 移动至指定格（消耗 1 附加动作） |
| `.a sN` | 以附加动作释放第 N 号技能（需技能允许附加动作时机） |
| `.a eat` | 食用治疗物品（对自己） |
| `.a give <目标>` | 将物品交给队友 |

#### 反应动作

| 命令 | 说明 |
|------|------|
| `.e d` / `.e 闪避` | 闪避 |
| `.e c` / `.e 反击` | 反击（近战技能） |
| `.e b` / `.e 格挡` | 格挡（需盾牌） |

#### 其他

| 命令 | 说明 |
|------|------|
| `.i end` | 主动结束回合（放弃剩余主动作） |
| `.u xxx [sN]` | 使用物品的第 N 个能力 |
| `.g <物品名> @目标` | 转移制造物 |
| `.as <序号>` | 将自身绑定为某序号玩家 |
| `.alist` | 查看当前可用行动列表 |
| `.bta end` | 结束战斗 |

### 五、控制状态（v1.4.0 新增）

战斗中可能被施加以下状态效果，每种状态由 `辅助效果` 字段声明，`持续回合` 决定时长。同名状态重复施加时，取较长剩余时间。

| 状态 | 禁止的行动 | 允许的行动 |
|------|-----------|-----------|
| **沉默** | `.s1+` 及 `.a sN`（主动/附加技能） | `.s0`、移动、被动技能 |
| **缴械** | `.s0` 基本攻击 | 技能、移动 |
| **击晕** | 移动、攻击、技能、**所有反应** | `.a eat`、`.a give`、`.i end` |
| **禁锢** | 显式移动、自动接近 | 射程内攻击/技能 |
| **隔离** | 自身被动技能及其产物（暂停不生效、不倒计时） | 主动行为 |
| **减速** | 降低有效 MOV（倍率相乘） | 其余不受限 |
| **飞行** | — | MOV+8；非飞行单位无法近战飞行目标 |

> 击晕的 `辅助效果值` 为 `0` 时，该角色不可被伤害性攻击/技能选中（「击晕保护」），非伤害控制/辅助效果仍可选中。值为 `1` 时正常可选中。

---

### 六、移动与地形

- 使用网格坐标（如 `A1`, `C5`），**Chebyshev 距离**（`max(|Δcol|, |Δrow|)`）。
- 每回合总移动力 = 有效 MOV（受 buff/领域/飞行/减速修正）。
- 攻击时自动向目标移动（消耗移动力），回合结束时自动退回锚点。
- 禁锢/击晕状态下移动力强制为 0。

---

### 七、伤害结算顺序

```
伤害骰 → AUX 倍率(1/3/19) + 固定值(2) → 护盾吸收 → HP 扣减 → 致死判定
```

- **伤害贯穿**（pen）：极难/大成功时额外触发满值加成。
- **护盾**：部分角色/召唤物拥有护盾值，优先吸收伤害（吸收率由 `shield_block_rate` 决定）。
- **濒死**：HP 归零后进入濒死状态，可被治疗拉回；无治疗手段则判定阵亡。

## 乙、变身与魔法规则

### 一、变身效果（.hs）

```
HP   = HP_original  × (5 + level)
MP   = MP_original  × (2 + 0.5×level)
APP  = min(APP_original + 60, 80)
斗殴/闪避/枪械 += 20（上限 80）
体格 += 1 → DB 上升一级
MOV  += 2
```

变身完成后可使用全部法术。`.bta start` 时尚未变身的角色自动完成变身。

### 二、解除变身效果（.unh）

1. HP 变为 `上取整(当前HP / (等级+5)) + 2`
2. MP：若大于变身前最大 MP 则舍去多余值
3. **SAN 与 CON 检定**（若此次变身中使用了超过两次法术或进行了战斗）：
   - SAN ≥ 30：0/1d5 SAN，CON 1d3/0
   - SAN < 30：1/1d6 SAN，CON 1d3+1/0
   - SAN < 20：1d3/1d8 SAN，CON 1d6/1d3
   - SAN < CM：损失减半
4. 回复初始属性与技能
5. 在第 1, 3, 6, 10, 15 … 次有效变身后等级 +1（见升级规则）

### 三、升级规则与魔能进阶

1. 等级达到 **4, 8, …** 有机会习得一个**深层魔法**
2. 等级达到 **2, 6, 10, …** 有机会获得一个新的浅层魔法（初始时确定 Lv2 浅层魔法）
3. 任意一次升级可选择一个已掌握魔法，熟练度 +30
4. 熟练度获取途径：大成功/成功终结 +30；使用技能的每场战斗结算 +1d20
5. 熟练度阈值：**30 / 60 / 90 / 100**
   - 30/60/90：获得小型升级（伤害骰 d4→d6→d8→d10→d12、吟唱-1/4、持续+1/3、致死+2、领域半径+1 等，单一过程）
   - 100：对魔法进行一次**深化**，升级为更深层的模式
   - 时间相关魔法必然是深层魔法

**CM 值**（代替原版克苏鲁神话技能）：代表对魔法知识与世界本源的了解程度。需要 CM 检定时，掷骰为灵感 + `.rd+CM` 的组合。快捷指令 `.cm`。驾驶与信用检定同样使用 `.rd+驾驶/信用` 代替 `.ra`。

## 附：掷骰输出格式

一次标准攻击的返回文案如下：

```
{攻击方}的【{技能名}】检定:
  D100={出目}/{判定值}{奖惩过程} {成功等级}

{防御方}的反应：【闪避/反击[:技能名] {数值}】检定:
  D100={出目}/{判定值}{奖惩过程} {成功等级}

{胜者} 胜利！ {大成功/极难成功/困难成功}

{败者} 受到伤害: XdY+Z = {计算过程} = {结果}
致死骰: 1d{当前HP×2} = {出目} [≤/>] {阈值}, {成功/失败}
{败者} 剩余 HP: {剩余值}
```

## 附：自动化模式

| 模式 | 指令 | 说明 |
|------|------|------|
| setab 0 | `.setab 0` | 最小自动化：仅处理单次攻击-反应-伤害结算 + 变身/解除变身 |
| setab 1 | `.setab 1` | 完全本地模式：JS 端独立管理先攻、回合、地图、状态（**默认**） |
| setab 2 | `.setab 2` | Python 后端模式：全部逻辑由 Flask 后端处理，JS 仅负责渲染响应 |
